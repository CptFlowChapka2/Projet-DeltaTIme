DOCU TECHNIQUE : DeltaTime

================================================================================

Classe Abstraite :

Doers : Classe comune de tous les scripts qui ont pour but de faire quelque chose . 
Par default, ils contiennent tous 
    —Un GetSet qui à Reference à un Manager .
    — Les Fonctions Get et Set AllUsefulParameters , par default vide qui permete d'uniformisé les récuperation et aplication de variable.
Standart d'utilisation 
    —Un doer Doit avoit un nom commençant par un verbe .
    — Il doit avoir une reference vers son manager typer .
    — Un Doer contient Un groupe logique d'action ,si son scope s'étant on le casse en plusieur doers.
    — Les méthodes d'un Doer doivent expliciter leur logique internet => conquaçé les méthodes .

Manager: Classe commune à tout les script qui ont pour but de centralisé les réfrence et variable .
il contiennent tout les variable qui doive etre accédé par d'autre Doer .
Il posséde des méthode pour accéder correctement à une variable (Get...) ou une Action (Do...) .

par default ils contiennent tous :
    -une reference au Game Manager
    -Une Liste non Typer de tout leur Doer
    -Une méthode GetAllDoersOnGameObject , qui initialise la liste avec un GetComponentS
    -Une Fonction InitializeDoer qui :
        -out une réference typer du Doer
        -donne la réference manager au doer.
     -Les méthode Force Get et Set AllusefullData d'un Doer :
        -Si on Specifie le Type de Doer , il appliquerat la fonction Set ou Get de tout les Doer correspondant.
        -Sinon de tout les Doer


Si un Doer à besoin de quelque chose extérieur à sa logique interne (ex : variable globale) il doit passer par un Manager.
Si un Manager à besoin de quelque chose extérieur à ses prérocative (ex: un autre Doer que les siens) il doit passer par le Game Manager.

Game Manager:

Le Game Manager à pour but de centraliser  les manager entre eux par le biais de méthode de communication direct (Get de valeur , Call D'action ...) 
ou par le bias des Event .

Il posséde une reference à tout les manager .

pour initialiser tout les manager 2 méthode :
    -par refference public dans l'inspecteur (solution safe pour les manager dupliqué comme DanceFloor ou Player Manager)
    -Par la méthode GetAllManager(qui met tout les manager de la scéne dans une liste) + InializeManaer (out une refernec typer d'un manager + transmet la réference vers le gamemanager)

Le groupe de méthode Get permente d'accéder  à une variable d'un autre Manager
le groupe de méthode Do permete d'ordoner l'action d'un Doer extérieur
