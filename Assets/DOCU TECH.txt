================================================================================

Classe Abstraite :

Doers : 
Classe comune de tous les scripts qui ont pour but de faire quelque chose . 
Par default, ils contiennent tous 
    —Un GetSet qui à Reference à un Manager .
    — Les Fonctions Get et Set AllUsefulParameters , par default vide qui permete d'uniformisé les récuperation et aplication de variable.
Standart d'utilisation 
    —Un doer Doit avoit un nom commençant par un verbe .
    — Il doit avoir une reference vers son manager typer .
    — Un Doer contient Un groupe logique d'action ,si son scope s'étant on le casse en plusieur doers.
    — Les méthodes d'un Doer doivent expliciter leur logique internet => conquaçé les méthodes .

Manager: 
Classe commune à tout les script qui ont pour but de centralisé les réfrence et variable .
il contiennent tout les variable qui doive etre accédé par d'autre Doer .
Il posséde des méthode pour accéder correctement à une variable (Get...) ou une Action (Do...) .

par default ils contiennent tous :
    -une reference au Game Manager
    -Une Liste non Typer de tout leur Doer
    -Une méthode GetAllDoersOnGameObject , qui initialise la liste avec un GetComponentS
    -Une Fonction InitializeDoer qui :
        -out une réference typer du Doer
        -donne la réference manager au doer.
     -Les méthode Force Get et Set AllusefullData d'un Doer :
        -Si on Specifie le Type de Doer , il appliquerat la fonction Set ou Get de tout les Doer correspondant.
        -Sinon de tout les Doer


Si un Doer à besoin de quelque chose extérieur à sa logique interne (ex : variable globale) il doit passer par un Manager.
Si un Manager à besoin de quelque chose extérieur à ses prérocative (ex: un autre Doer que les siens) il doit passer par le Game Manager.

Game Manager:

Le Game Manager à pour but de centraliser  les manager entre eux par le biais de méthode de communication direct (Get de valeur , Call D'action ...) 
ou par le bias des Event .

Il posséde une reference à tout les manager .

pour initialiser tout les manager 2 méthode :
    -par refference public dans l'inspecteur (solution safe pour les manager dupliqué comme DanceFloor ou Player Manager)
    -Par la méthode GetAllManager(qui met tout les manager de la scéne dans une liste) + InializeManaer (out une refernec typer d'un manager + transmet la réference vers le gamemanager)

Le groupe de méthode Get permente d'accéder  à une variable d'un autre Manager
le groupe de méthode Do permete d'ordoner l'action d'un Doer extérieur 


//Player System//
PlayerManager : Manager
Manager pour le systéme player .

Posséde les Doers :

-ReadInput
-AnalyseInput
-MovePlayer
-UpdateWhenHit

Variable public notable :
player id : permet de spécifier le joueur actuel , définit dans l'inspecteur.
currentPlayerCoords: position actuel du Player en coordoné relative du Dancefloor.
InputActionName : à initialiser dans l'inpecteur avec "Player1Move" ou "Player2Move".par rapport à l'input map.
inputsThisMeasure: La liste des input en Vecteur2Int fais à la derniére mesure complété.
inputsThisMeasureCache : La liste des input en Vecteur2int fais lors de la mesure actuel  (ATTENTION IL FAUT FORCE GET et SET REGULIERMENT POUR QU'ELLE SOIT A JOUR)
currentTileId: Reference vers la TileID actuelle.

Méthode Public:
DoTeleportPlayerToCoords(Vector2Int coords) :  Teleport le joueur à une case spécifier sur le dance floor associé.


ReadInput : Doer

A pour charge de lire les Input d'un joueur fais cette frame  et les traduire en Vector2Int
Renvoi une valeur de 0 si aucun Input à étais fais cette frame .

AnalyseInput : Doer

Récupére les Input de ReadInput et les filtre .
Si un il n'y as  ut d'input on skip.
Si un input à deja étais traité sur ce Beat on  l'action est annulé.
Si l'input est une diagonal on l'annule ,priorisant l'horizontal.
Si on l'input est effectué off Beat ,on transforme l'input en Zero.
Sinon on compte le nombre de mouvemente réussi .

Aprés on ajoute  l'input (qui est soit valide soit Zero) dans Input THis measure Cache.

MovePlayer : Doer

Bouge le joeur  si l'input de ReadInput n'est pas 0

Le mouvment est une teleportation qui actualise les paramétre changer (current coord et currente tile)
la teleportation est clmaper dans les les limite de l'espace jouable du dancefloor

UpdateWHenHit : Doer

Change le materieu du joueur si le joueur à étais toucher .

contient un temps d'invulnarabilité .

vérifie si le joeuur est hit en checkant le nombre de projectile sur la current Tile.
